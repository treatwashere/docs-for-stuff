1. Document Structure

HTML5 documents require boilerplate elements to structure the page hierarchy and provide metadata to browsers.

TagDescription
<!DOCTYPE html>Defines the document type as standard HTML5.
<html>Root element wrapping all page content.
<head>Container for metadata, scripts, stylesheets, and titles.
<body>Contains all rendered text, visuals, and markup.

2. Text & Headings

Organize textual information using heading hierarchies and formatting tags.

TagDescription
<h1> to <h6>Heading tags representing structural hierarchy.
<p>Defines standard paragraph blocks.
<strong>Applies bold emphasis for important content.
<em>Applies italicized emphasis.
